# Benny Blends

Barbershop website — precision cuts, clean fades, sharp lines.

Black & silver aesthetic, chrome metallic logo, one-click booking that emails appointment requests.

**Instagram:** [@bennyyblendss](https://instagram.com/bennyyblendss)

## Run

Open `index.html` in any browser. Zero dependencies, single file.

## Booking

The booking form uses [FormSubmit](https://formsubmit.co) to email appointment requests. The first submission triggers a one-time confirmation email to activate the address.
